# 02 — Terminology

| Term | Meaning |
|------|---------|
| CRQC | Cryptanalytically-relevant quantum computer. Shor’s algorithm breaks RSA/ECC in polynomial time. |
| Grover | Grover’s search halves the effective key length of symmetric ciphers and hash outputs. |
| PQ | Post-quantum cryptographic algorithm (e.g., ML-KEM, ML-DSA, SLH-DSA). |
| Hybrid | Combination of classical + PQ key exchange or authentication (e.g., X25519Kyber768). |
| Transitional | Endpoint supports both classical and PQ algorithms; not fully PQ-safe until classical is deprecated. |
